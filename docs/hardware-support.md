# 本机适配结果

验证日期：2026-09-27。机型 81BR / ideapad 720S-13ARR，BIOS 6KCN40WW，Lenovo ACPI Virtual Power Controller 驱动 15.11.29.70。

普通用户（非提升权限）成功访问 EnergyDrv。正常命令后观测回读 133，强冷后观测回读 3。初始化和恢复会检查正常回读；强冷只接受本机实测的 3，不将任意变化当作强冷成功。此映射只适用于本版本明确限定的机型及 BIOS，不是通用 Lenovo 协议保证。

实际强冷建立存在延迟，原先短等待不足。实现改为一次发送、有限次数等待回读；维持周期从命令发送时刻计时，约每 8.5 秒恢复／重新进入强冷。30 秒实际控制验证覆盖多个维持周期，最终正常恢复回读 133。回读证明命令状态，不等同于 RPM 测量；用户此前已确认同一接口能实际改变本机风速。

停止维持后的 150 秒观察中没有获得稳定正常基线，不能依赖固件自动过期。首次开启强冷会启动一个本地恢复保护进程，以继承的进程句柄等待主进程退出；并持有实例互斥对象，防止恢复期间新控制实例竞争。主进程结束后发送正常命令再释放控制权。正常退出和单独强制结束测试进程两种场景均观察到恢复 133。

保护进程在首次手动强冷后保留至本次软件会话结束，等待时不轮询。结束整个进程树、系统冻结、驱动卡死或关机导致双方同时结束不在此机制保证范围内。下次启动仍首先执行正常恢复。

标准 Win32_Fan / ACPI 热区查询未返回可用读数。未把 ACPI 热区等同于 CPU 温度；低速、温度曲线、精确 RPM 和独立 CPU/GPU 风扇控制均未开放。保护失效、型号不匹配或驱动错误时拒绝强冷并提示。

适配测试工具为 FanProbe.exe，仅开发目录包含：

| 命令 | 行为 |
| --- | --- |
| `--read` | 只读原始状态，不修改模式 |
| `--normal` | 发送正常命令，读取状态，结束前再次恢复 |
| `--controller-test` | 经完整状态机进行约 30 秒强冷和正常恢复 |
| `--expiry-test` | 单次强冷后观察 150 秒，再恢复正常 |
| `--guard-crash-test` | 强冷确认后终止测试父进程，验证恢复保护 |

后三项会实际改变风扇状态，仅用于本机开发验证，不随用户便携包分发。
