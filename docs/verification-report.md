# 0.3.0 安静模式与温度口径

更新日期：2026-10-09。参考 Lenovo-Fan-Control v0.4 的固定源码与用户提供 EXE 的 SHA-256 已在 `RESEARCH.md` 核对。参考工具没有第三个安静写入值；其低速实现每 5 秒重发原厂正常命令。本版据此加入安静策略，要求温度低于 80°C 且 25 秒内更新，超温、失效或过期均切回原厂自动。控制器单元测试覆盖周期写入、超温回退和读数过期回退；Release core/monitor 测试通过。已安装程序日志于 16:41 记录安静切换（回读 133）及约两秒后的自动恢复（回读 133），未覆盖持续维持周期。尚未验证安静档的实际风速、散热效果及电源生命周期，不能将驱动回读当作 RPM 验证。

用户决定暂将同一 APU 的核显适配器温度显示为 CPU 温度；原始来源仍为 WDDM/ADL GPU 适配器，独立 CPU 温度传感器继续不可用。本机只读采样得到 CPU/GPU 成对温度 53、58、50°C。安静保护使用这个代理值，不能证明它覆盖 CPU 最高热点。顶部 CPU/GPU 两个温度块已合并为一个 Temperature 区。长时验证仍暂停。最终 0.3.0 可执行文件 SHA-256：`9F9C2A7EE123ED64E0A53B0D3A011924C896094FA6595C666773D31B67F03616`。
